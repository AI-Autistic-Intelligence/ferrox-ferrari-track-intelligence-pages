## Architecture & Features
- **Vehicle Dynamics & Friction Circle Cockpit**: Comprehensive telemetry analysis cockpit for Scuderia Ferrari vehicle dynamics, G-G friction envelope, corner apex analysis, and stint tyre degradation.
- **Genuine Telemetry**: Based on live public timing and telemetry feeds (OpenF1, Jolpica, Open-Meteo).
- **Interactive Telemetry & Track Map**: Real GPS track coordinates, corner apex velocity detection, aero balance, and telemetry replay.
- **Client-Side Autonomous Deployment**: Pure reactive HTML5/CSS3/JavaScript ES modules hosted on GitHub Pages with zero server setup required.
